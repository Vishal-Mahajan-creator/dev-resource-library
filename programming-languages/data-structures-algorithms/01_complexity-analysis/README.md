Notes on Complexities
O(1) → Constant time. Accessing an element in an array.

O(n) → Linear time. Iterating through all elements.

O(n²) → Quadratic time. Nested loops over the same dataset.

O(log n) → Logarithmic time. Divide‑and‑conquer (binary search).

O(n log n) → Typical for efficient sorting algorithms (merge sort, quicksort).

O(2ⁿ) → Exponential time. Subset generation, brute‑force recursion.

O(n!) → Factorial time. Permutations, traveling salesman brute force.
