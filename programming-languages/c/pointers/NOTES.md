# C Pointers — Complete Notes

## Pointer
Variable that stores memory address.

Syntax:
datatype *pointerName;

Example:
int *ptr;

---

## Operators

& → Address of variable  
* → Dereference value

---

## Why Pointers?
- Memory management
- Dynamic allocation
- Arrays handling
- Function efficiency
- Used in OS & Embedded systems

---

## Pointer Types
- Null pointer
- Wild pointer
- Dangling pointer
- Void pointer

---

## Call by Value
Copy passed → original unchanged.

## Call by Reference
Address passed → original changed.

---

- Swap using pointer
