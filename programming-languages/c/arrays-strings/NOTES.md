# Arrays and Strings in C

## Array
Collection of same datatype stored in contiguous memory.

Syntax:
datatype arrayName[size];

Example:
int arr[5];

Index starts from 0.

---

## Traversing Array
Using loops to access elements.

for(i=0;i<size;i++)

---

## Strings
Character array ending with '\0'.

Example:
char name[20];

---

## String Functions
strlen() → length  
strcpy() → copy  
strcat() → join  
strcmp() → compare

---

## Important Concepts
- Arrays store multiple values
- Strings are arrays of characters
- Memory is continuous
