# C Structures

## Structure
User-defined datatype used to group variables.

Syntax:
struct Name {
   datatype member;
};

---

## Access Members
dot operator (.)

example.name

---

## Array of Structure
Used to store multiple records.

Example:
students[10]

---

## Structure Pointer
Use arrow operator (->)

ptr->member

---

## Difference

Structure → Different datatype values  
Array → Same datatype values

---

## Real Usage
- Student records
- Employee database
- File systems
