# C++ Inheritance Complete Notes

## Definition
Inheritance allows reuse of existing class properties.

## Types
1. Single
2. Multilevel
3. Multiple
4. Hierarchical
5. Hybrid

## Diamond Problem
Occurs in multiple inheritance.
Solved using virtual base class.

## Constructor Order
Base → Derived

## Advantages
- Code reuse
- Extensibility
- Polymorphism support
